# ========================================
# Picard 自動整理コマンド（改良版）
# ========================================
# 重要:
#   - REMOVE_EMPTY は意図的に無効化しています。
#     マッチングに失敗したファイルを消さないため、絶対に有効化しないでください。
#   - マッチングしなかったファイルは music_download に残ります。
#     Picard の GUI で手動マッチングしてください。
# ========================================

# 対象フォルダを読み込み（music_download 配下をすべて取り込む）
LOAD C:/Users/<ユーザー名>/Documents/YoutubeDownload/music_download

# クラスタリング（アルバム単位・フォルダ単位でまとめる）
CLUSTER

# ----------------------------------------
# 第1段階: 既存タグ（アーティスト/タイトル）で検索
# ----------------------------------------
LOOKUP
SAVE_MATCHED
REMOVE_SAVED
# REMOVE_EMPTY   ← 意図的にコメントアウト（未マッチを残す）

# ----------------------------------------
# 第2段階: 音声指紋 (AcoustID) でスキャン
# ----------------------------------------
FINGERPRINT
SCAN
SAVE_MATCHED
REMOVE_SAVED
# REMOVE_EMPTY   ← 意図的にコメントアウト

# ----------------------------------------
# 第3段階: もう一度スキャン（取りこぼし回収）
# ----------------------------------------
FINGERPRINT
SCAN
SAVE_MATCHED
REMOVE_SAVED
# REMOVE_EMPTY   ← 意図的にコメントアウト
